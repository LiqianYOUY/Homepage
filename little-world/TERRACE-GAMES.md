# 露台游戏维护

帐篷、藤椅和茶桌的物件点击及两个热点使用同一个密码入口。未解锁时只有密码表单；验证成功后显示两款游戏，选择后才下载、解密并创建 iframe。密码仅在当前弹窗的内存中保留，关闭后清空，正在请求的包也会取消。没有将密码或明文游戏保存到 localStorage、服务器或 Git 仓库。

`assets/games/access.bin` 是小体积解锁令牌；另外两个 `.bin` 各包含完整 HTML、脚本、字体和图片。格式为 `YOUHOME1`、16 字节随机 salt、12 字节 IV、AES-256-GCM 密文与 16 字节认证标签。密钥使用 PBKDF2 / SHA-256 / 210,000 次迭代从密码派生。修改密码需要重建全部三个包。

这是静态网站的共享密码入口。短数字密码仍可能被离线猜中，已解锁的访客也能保存解密内容；不能当作强身份验证或代替作品使用授权。

## 重建

现有游戏源码保留在网站目录外的 `../juice-bay` 和 `../sling-birds`；构建过程只读源码，不改变它们原来的发布配置。它们的依赖必须已安装。使用 Node.js 22.13 或更新版本，在网站仓库根目录运行：

```sh
read -s TERRACE_GAME_PASSWORD
export TERRACE_GAME_PASSWORD
node scripts/build-terrace-games.mjs
unset TERRACE_GAME_PASSWORD
```

脚本会检查输出没有外部资源引用、验证正确密码和错误密码，并写入三个加密包。明文调试输出只进入临时目录，禁止复制到公开目录。修改包后同步更新 `terrace-games.js` 的资源版本，以便已访问过的浏览器获取新包。

饮料游戏复用果汁小岛，弹弓游戏复用捣蛋鸟；捣蛋鸟使用自绘几何、合成音效及项目自己的背景，没有引入原版 Angry Birds 游戏文件。游戏最高纪录沿用各自的浏览器本地存储。小屋界面保留中英文入口，游戏沿用原有中文内容。
