# 小小栖居 · A Little World

小尤的三维小家。好好吃饭，好好睡觉，越来越好。

拖动空白处看看家，滚轮拉近，点击小物件使用。底部可以去客餐厅、书房、厨房、主卧和露台；「走进家里」后，地面出现前后左右箭头：点一下走一步，长按连续走，拖动空白处转头；电脑也保留 WASD / 方向键与 Esc。住宅界面使用昵称和插画头像。

手机上的朋友卡片和小橘卡片默认收起，点昵称旁的小箭头展开；电脑也能收起，两种尺寸分别记住偏好。

## 在这里坐一会儿

- **入户门边的黑色中控盒**：直接点击打开「家的小管家」，控制室内灯光、电动窗帘、自动打扫和电视。中控入口在三维门边。
- **门与收纳**：房门可以点击或拖动开合，餐椅可以拖动。五组靠墙衣柜内有挂衣、衣架、叠衣与层板；厨房储物柜内有锅、餐盘、杯子和食材罐。柜门前有家具时会保留安全开度，对向橱柜会先关闭再打开。
- **日常厨房**：可点击出水的龙头、米白色冰箱、带间隙的冷藏机身，台面上的微波炉、电饭锅、锅碗与厨具。
- **露台花园**：客餐厅和书房外侧的露天木露台有两扇可推拉的玻璃门、栏杆、休息座位和八只花箱。点花箱或浇水壶，选择薄荷、迷迭香、小雏菊、薰衣草；浇水、施肥、重新播种，花开后收下小花。土壤湿润时不用反复浇水。原冬日花房的花盆也保留着。
- **陪伴小橘**：连续柔软曲面的橘白小猫会散步、跑动、迎接、靠近鼠标、踮脚讨摸，也会低头吃粮、喝水和动嘴喵叫。猫粮盆、水盆一直留在客厅；日常照顾有记录。扫地机器人会清理她留下的污点，互相避让后回充。洗衣区有扫帚、拖把、簸箕和立式吸尘器。
- **书桌与书架**：电脑打开可编辑、换色、拖动的便签；书架有《平面国》《时间机器》《物种起源》《天文学简史》的完整英文公版读本，可直接阅读、下载、调字号和记进度，也能添加自己的链接。
- **原型工作室**：小窗口展示 MoodBall、compact washer、智能药盒和 FoodCare + SeniorCare，使用已有公开项目的素材。完整作品集在外部原站打开，网址或原站可能显示原作者账号。
- **小音响**：Flower Dance 的 Spotify 嵌入与原平台入口；也可导入自己的音频，播放、暂停并看唱片转动。在线音乐受平台、账号和网络可用性影响。
- **客厅电视**：达令港实拍烟花、悉尼海港大桥跨年烟花的原平台视频，可以放大或放回三维电视屏幕。可选择自己的本地视频临时播放，文件不上传。本项目没有导出或生成住宅导览视频。
- **关于屋主**：右上角粉色马尾头像介绍小尤，也有简单互动提示和来访记录。顶部数字时钟和门边挂钟都使用 Australia/Sydney 当前时间及夏令时。

## 在线版与本机版

**GitHub Pages 在线版**已经接入共享数据库。后台按公网 IP 分配昵称和可爱头像，按悉尼日期对同一 IP 每天记一次到访。昵称在同一 IP 下保持一致，换 IP 时可能变化；多个访客共用 IP 时会合并计数，因此这是到访记录而非精确人数。原始 IP 不写入留言数据库，只保存以服务器密钥生成的识别值。明信片公开给所有到访者阅读。

便签、书目、音乐收藏、植物、猫咪和门窗状态仍属于各自浏览器，不会因为共用 IP 而共享。公网连接不依赖第三方 Cookie，手机浏览器可以直接使用；临时断网时页面明确显示本机留言簿，离线留言不会自动公开上传。

**桌面本机版**：双击「打开3D家.command」，保留启动器窗口，访问显示的本机地址（通常为 http://127.0.0.1:8765/）。需要 Python 3，也可在项目目录运行 `python3 serve.py`。不要直接双击 index.html；无需 npm 或 Blender。

本机 Python 服务用匿名 Cookie 区分访问同一服务的身份，以 SQLite 保存该服务的真实日到访及留言。它仅监听 127.0.0.1，不是公网共享后台。旧版屋主资料只迁移给本机已确认的屋主；在线陌生访客不会承接这些便签。

## 个人记录

设置中可以导出、导入自己的便签与生活记录 JSON。清除浏览器数据前请自行导出需要保留的内容。本机版还会保存个人资料到受保护的 `data/`，该目录不会放进公开发布包。

本地音频使用当前浏览器的 IndexedDB；阅读字号与进度也在浏览器里，音频文件不包含在 JSON 导出中。本地视频仅保留在当前播放会话。网站上线不会上传桌面的个人记录。

## 模型与维护

`apartment.glb` 是原住宅基础模型。柜体修补、露台、门窗、猫咪和其他交互由 JavaScript 实时加入；直接把 GLB 导入 Blender 不会包含这些运行时对象。原图缺少完整施工尺寸，模型用于空间和交互概念展示。

桌面完整项目保留建模源码和检查报告；公开发布包仅包含运行必需的页面、模型、素材、读本和许可。旧查看器与旧项目压缩包已删除。共享后台源码另存于桌面项目的 source/community-service，部署密钥不包含在源码中。
