# 小小栖居 · A Little World

小尤的三维小家。好好吃饭，好好睡觉，越来越好。

拖动空白处看看家，滚轮拉近，点击小物件使用。底部可以去客餐厅、书房、厨房、主卧和露台；「走进家里」后，地面出现前后左右箭头：点一下走一步，长按连续走，拖动空白处转头；电脑也保留 WASD / 方向键与 Esc。住宅界面使用昵称和插画头像。

手机上的朋友卡片和小橘卡片默认收起，点昵称旁的小箭头展开；电脑也能收起，两种尺寸分别记住偏好。朋友卡片展开时置顶，整张小橘卡片暂时隐藏；收起朋友卡片后恢复小橘原来的展开状态。

## 在这里坐一会儿

- **入户门边的黑色中控盒**：直接点击打开「家的小管家」，控制室内灯光、电动窗帘、自动打扫和电视。中控入口在三维门边。
- **门与收纳**：房门可以点击或拖动开合，餐椅可以拖动。主卧与次卧靠墙衣柜内有连衣裙、长礼服、衬衫、西装与长裤，还有衣架、叠衣与层板；儿童房使用沿实墙连续布置的推拉衣柜、收纳柜与开放书柜。厨房储物柜内有调料瓶罐、杯碟碗锅、刀叉勺托盘、谷物罐和零食。柜门前有家具时会保留安全开度，对向橱柜会先关闭再打开。
- **日常厨房**：烤箱左侧是与高柜等高的双开门智能冰箱，门上有大屏；屏幕的 `04°` 和 `−18` 示意数字已按正面视角修正左右顺序与字形，没有连接实际温度传感器。保留可点击出水的龙头、台面上的微波炉、电饭锅。锅、平底锅、碗、茶杯、马克杯和花盆使用真实内壁与底部，杯柄、壶嘴及锅铲开孔；厨房补充长柄汤勺、打蛋器和硅胶夹。
- **露台花园**：客餐厅和书房外侧的露天木露台有两扇可推拉的玻璃门、栏杆、两把藤编软垫扶手椅、条板木桌、烧烤推车和八只花箱。点花箱或浇水壶，选择薄荷、迷迭香、小雏菊、薰衣草、向日葵或郁金香。按真实经过的天数生长，关闭网页后也计算；花开后可剪枝，放入客厅、餐厅或室内阳台桌上的花瓶。凋谢后可清理重种。室内五盆静态绿植增加卷曲叶片、叶柄、茎、土壤和花盆内壁。详细品种周期、养护假设和资料见 [植物时间与照顾](PLANT-LIFECYCLE.md)。
- **客厅棋牌**：电视前的圆角木茶几摆着棋盘、卡牌、骰子和零食；点击棋牌物件或提示，选择五子棋、围棋、象棋、国际象棋、斗地主或家常四人麻将，与本地电脑对局。国际象棋使用统一的实心棋形，白棋为纯白填充，深浅格上均保留清晰边缘。可重新开局，窗口收起时暂停电脑，回到同一页面继续；刷新页面会清空对局。界面支持中英文，规则范围见 [棋牌桌玩法](GAMES.md)。
- **窗边钢琴**：沙发另一侧的西侧窗边有带琴凳、谱架和踏板的电钢琴，面向室内并避开承重柱。点击打开 C4 至 C6 的两组八度琴键，可用鼠标、触屏或电脑键盘弹奏和弦，调节延音及音量。小屏幕可用琴键下方的左右箭头横向移动键盘；电脑方向键切换焦点，回车弹奏选中的琴键，按住空格延音。音色由 Web Audio 合成。
- **陪伴小橘**：连续柔软曲面的橘白小猫会散步、跑动、迎接、靠近鼠标、踮脚讨摸，也会低头吃粮、喝水和动嘴喵叫。猫粮盆、水盆一直留在客厅；日常照顾有记录。扫地机器人会清理她留下的污点，互相避让后回充。洗衣区有扫帚、拖把、簸箕和立式吸尘器。
- **书桌与书架**：工作室使用带控制面板的电动升降桌和人体工学网椅，点击控制面板切换坐姿与站姿高度，桌面物品一起升降。主显示器打开作品集（中文「作品集」、英文「prototype studio」），左侧小显示器已移除；桌上是含独立按键与字符的 61 键键盘，以及带支架、软垫头梁和旋转耳罩的降噪耳机模型，耳机会随桌面一起升降。便签从灵感板或朋友面板的快捷入口打开，可编辑、换色、拖动；书架有《平面国》《时间机器》《物种起源》《天文学简史》的完整英文公版读本，可直接阅读、下载、调字号和记进度，并收录《The Adventures of Sherlock Holmes》和《Pride and Prejudice》的公开阅读链接。线上书架可点击「分享给朋友」或「发布到公共书架」，发布成功后其他访客打开书架即可看到；「只保存到我的书架」继续保留个人书目。
- **原型工作室**：小窗口展示 MoodBall、compact washer、智能药盒和 FoodCare + SeniorCare，统一使用与 compact washer 同风格的 SVG 产品线稿：MoodBall 的球形编织结构、圆形药盒与胶囊、FoodCare 的手机与食物识别硬件。四张卡片的「查看项目」分别在新标签页打开对应的完整项目，底部另有完整作品集入口。完整作品集的 Playground 也可直接进入「小小栖居 · Welcome to my home」。外部原站及网址可能显示原作者账号。
- **小音响**：Flower Dance 的 Spotify 嵌入与原平台入口；也可导入自己的音频，播放、暂停并看唱片转动。在线音乐受平台、账号和网络可用性影响。
- **客厅电视**：打开先看小尤的 Uluru 日出与日落旅行片段，视频随网站提供，不依赖外部视频平台。也能切换达令港烟花、悉尼海港大桥跨年烟花；外部平台没有连上时，可一键回到 Uluru。画面可以放大或放回三维电视屏幕，旅行视频切换大小时保留播放进度。访客还可以选择自己的视频临时播放，这些自选文件不上传。网站播放仍需要网络；本项目没有导出或生成住宅导览视频。
- **关于屋主**：右上角粉色马尾头像介绍小尤，也有简单互动提示和来访记录。顶部数字时钟和门边挂钟都使用 Australia/Sydney 当前时间及夏令时。

## 房间与语言

右上角的 EN / 中文按钮切换界面、物件提示、弹窗和内嵌作品/阅读器介绍，并记住语言选择。已有的中英并列内容、书籍英文原文，以及自己的便签、留言和收藏名称保持原样。

室内阳台保留桌子，四把椅子换成两张可倚躺的沙袋沙发。入户门旁的儿童房采用一张上窄下宽的子母上下铺，长边靠西侧卫生间的墙面，梯子朝房间中央。东侧窗边并排放两套独立学习桌椅，窗前不放高床或高柜；北侧实墙沿线布置低收纳柜、推拉衣柜和开放书柜，靠近房门的一端收纳玩具和书包。旧的两套床桌柜一体家具已替换，保留入口、床边及两套书桌之间的通路。

相邻卧室保留双人床并增加书桌与椅子；两间房的墙体接缝已修补，挡住玻璃一侧的墙段已移除。卧室增加可开合窗帘，卫生间增加洗漱用品；马桶、台盆、浴缸和淋浴底盘使用带内壁与排水口的真实凹腔，水槽下方台面和柜板留出开孔。主卧门边的绿植移到浴缸与台盆转角。主卧移除衣柜中间的凳子，联排衣柜改为三扇门，中间是带房间反射的全身镜。

儿童房门口的低收纳柜摆放兔子和小熊毛绒玩具，下层收好薄荷绿小书包；两套窗边书桌放有展开的作业本、笔筒与彩色铅笔、书本、尺子和橡皮。物品按实际台面和柜内层板定位。

入户门向室外打开；门内侧靠墙增加三段薄型鞋柜，柜门在柜内平移，台面托盘放钥匙圈、素色门卡和钱包。原有户型地板边界保持不变。主卧阅读角改为开放式太空舱造型休憩椅，带灰绿软垫、暖色灯圈及可点击开关的阅读灯，灯状态保存在当前浏览器。主卧电视右侧摆放纤细衣帽架、衬衫围巾、帽子、包和收纳托盘，保留房门、衣柜开合和镜前空间。衣帽间中央增加带软座的圆角矮收纳岛台，台面摆首饰、手表托盘和折叠围巾，两侧留出绕行空间。

自动打扫开启时，凋谢植物会先保留 24 小时供访客清理；之后机器人打开实际门窗，在可通行路径上前往花盆，清理后返回充电。室内阳台增加了可开合的推拉入口。家具、升降桌和门窗同时参与通行检查。

## 洗衣日

洗衣间统一铺设浅色瓷砖。点击下方洗衣机或上方烘干机打开洗衣面板：首次会有 2–5 件随机衣物，之后每 14 天准备新一批。启动 45 分钟日常洗，完成后手动移入上方烘干机，再启动 60 分钟温和烘干，结束后叠好收起。滚筒中显示同一批衣物，离开网页后继续按真实时间计时。

最多保留一批待处理衣物；长期没有回来时，错过的周期合并成最近一批，刷新不会重复生成。衣物与进度保存在浏览器，也包含在原有生活记录备份中。

## 房间里的晨昏

房间随悉尼（Australia/Sydney）的真实时间与当天日出日落自动调整，顶部不再提供日夜切换按钮。太阳高度控制日照强度、光线方向和阴影；日出日落前后逐渐过渡到朝霞与晚霞的暖色，露台窗边有淡淡的斜光，关上窗帘后光束随之减弱。室内灯仍由「家的小管家」控制。

日照在本机按经纬度与日期计算，支持季节变化和夏令时，不依赖天气接口，也不请求访客定位。每 30 秒更新，回到页面时立即同步；旧备份中的手动日夜偏好不再影响光照。这里呈现的是日照氛围，不模拟实时天气。

Loading 主文案为「正在把家收拾好…」，小字为 “Making room for you…”，下载进度与加载失败提示的小字也使用英文。

验证：使用 Node.js 22.15 或更新版本，在 `little-world/` 目录运行 `node --test tests/*.test.mjs`，覆盖日照、双语文案、钢琴音高/和弦、桌面升降、实例碰撞、卫浴凹腔、洗衣周期、备份恢复、植物生命周期、花瓶库存和真实模型中的机器人路径。棋牌测试检查合法着法、胜负与和局、提子与劫、特殊棋步、牌型、吃碰杠胡、牌张守恒和电脑轮转；儿童房测试检查子母上下铺、窗边双书桌、旧家具与碰撞移除、门扇扫掠、入口至书桌通道及柜门状态；冰箱测试从正面和左右斜面相机投影检查数字顺序、数字 4 的方向及遮挡。自动检查不替代浏览器的画面与实际声音验收。

## 在线版与本机版

**GitHub Pages 在线版**已经接入共享数据库。后台按公网 IP 分配昵称和可爱头像，按悉尼日期对同一 IP 每天记一次到访。昵称在同一 IP 下保持一致，换 IP 时可能变化；多个访客共用 IP 时会合并计数，因此这是到访记录而非精确人数。原始 IP 不写入留言数据库，只保存以服务器密钥生成的识别值。明信片公开给所有到访者阅读。

便签、个人书目、音乐收藏、植物、猫咪和门窗状态仍属于各自浏览器，不会因为共用 IP 而共享。只有主动点击分享的书名与公开 HTTPS 链接会存入公共书架，其他访客重新打开或刷新书架即可看到；公共书目不包含便签、阅读进度、音乐或私人记录。重复链接（忽略阅读锚点）不会重复发布。个人编辑与移除不会改动公共书目。静态公开书单的新增条目也会送达旧访客，同时保留其个人改名、删除和收藏。公网连接不依赖第三方 Cookie，手机浏览器可以直接使用；临时断网时页面明确显示本机留言簿，离线留言不会自动公开上传。

**桌面本机版**：双击「打开3D家.command」，保留启动器窗口，访问显示的本机地址（通常为 http://127.0.0.1:8765/）。需要 Python 3，也可在项目目录运行 `python3 serve.py`。不要直接双击 index.html；无需 npm 或 Blender。

本机 Python 服务用匿名 Cookie 区分访问同一服务的身份，以 SQLite 保存该服务的真实日到访及留言。它仅监听 127.0.0.1，不是公网共享后台。旧版屋主资料只迁移给本机已确认的屋主；在线陌生访客不会承接这些便签。

## 个人记录

设置中可以导出、导入自己的便签与生活记录 JSON。清除浏览器数据前请自行导出需要保留的内容。本机版还会保存个人资料到受保护的 `data/`，该目录不会放进公开发布包。

本地音频使用当前浏览器的 IndexedDB；阅读字号与进度也在浏览器里，音频文件不包含在 JSON 导出中。访客自选视频仅保留在当前播放会话。小尤指定的 Uluru 旅行视频经过转码后随网站公开提供；便签等桌面个人记录不会上传。

## 模型与维护

`apartment.glb` 是原住宅基础模型。柜体修补、露台、门窗、猫咪和其他交互由 JavaScript 实时加入；直接把 GLB 导入 Blender 不会包含这些运行时对象。原图缺少完整施工尺寸，模型用于空间和交互概念展示。

桌面完整项目保留建模源码和检查报告；公开发布包仅包含运行必需的页面、模型、素材、读本和许可。旧查看器与旧项目压缩包已删除。共享后台源码保存在桌面 portfolio/community-service，部署密钥不包含在源码中。
