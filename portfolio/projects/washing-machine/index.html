01 / The question

What happens after
you press start?

Pressing start seems simple, but the machine has a few things to check first. Is the lid closed? Is there enough water? What should happen if you pause halfway through?

My design is for a small washer that you fill by hand. A rotating disc at the bottom, called a pulsator, moves the clothes through the water at low speed. The controls explain each step, including when you need to add water or close the lid.

The first version covers washing and draining. It does not include a spin cycle or water heating.

01 / Voice interaction

Say it.

“小洗衣机，暂停。”

The voice software recognises a set of Chinese commands and gives spoken replies without an internet connection. Each recognised phrase maps to a command such as start or pause.

02 / Physical controls

Press it.

Start. Pause. Choose.
Stop.

Buttons offer a familiar way to choose a programme, start, pause, or stop. A separate emergency stop is part of the hardware design.

03 / Local web interface

See it.

What’s happening?
What comes next?

A page on the local network shows what the machine is doing and lets you control it. The simulation lets me try adding water, pausing, resuming, and stopping a wash.

Behind the controls

Before the
water moves.

All three controls follow the same steps. After you ask to start, the software checks whether the machine is ready and prompts you to add water. The motor should only run once the water level, lid, and other safety checks allow it.

A Raspberry Pi handles speech and the wash programme. An ESP32 reads the sensors and controls the motor, with its own safety checks. If something goes wrong, the controller must check everything again before the wash can continue.

03 / From interface to object

Making room
for the real parts.

Drawings for the body, tub, and moving parts.
The next step is to check them against real components.

I use OpenSCAD to design the body and the parts that hold everything in place. The tub, shaft, bearings, and seals will be bought or machined. Their actual dimensions will help me adjust the design before assembly.

04 / Work in progress

From drawings and code
to a working machine.

What I have so far

  • Adjustable 3D models and specifications for the parts.
  • A Python controller, voice software, and a local web page.
  • ESP32 code and a plan for separate hardware safety checks.
  • A plan for building and testing the machine in stages.

What I need to test next

  • Whether the real parts fit together as drawn.
  • Whether the ESP32 code runs correctly on the hardware.
  • How well the microphone works near a running washer.
  • Leaks, how clothes move, and complete washes with water.
